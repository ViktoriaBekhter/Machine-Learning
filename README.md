# Machine-Learning

В представленных по ссылке кейсах были реализованы следующие задачи:
1. Применяла конструкцию «try-except» для обработки исключений.
2. Проводила анализ данных с использованием библиотек:
NumPy, Pandas, Matplotlib.pyplot, Plotly Express, Seaborn, Scikit-learn (включая модули
model_selection, ensemble, tree, linear_model, metrics), SciPy (включая stats и optimize), OpenCV
(cv2).
3. Обрабатывала пропущенные данные.
4. Строила различные диаграммы и тепловые карты корреляции для визуализации
взаимосвязей между переменными.
5. Создавала массивы NumPy для обучения модели и определяла оптимальное число
кластеров для набора данных с использованием методов силуэта и локтя.
6. Смоделировала и оценила производительность, обучила модели K ближайших соседей
(KNN).
7. Статистический анализ.– Выполнила однофакторный дисперсионный анализ (ANOVA) с использованием библиотек
NumPy и SciPy.
– Провела тест нормальности распределения:
Критерий Шапиро-Уилка
Тест Колмогорова-Смирнова (используя функцию kstest из модуля scipy.stats)
Тест д'Агостино на K² (normaltest(sample))
Корреляционный тест Пирсона
9. Рассчитала коэффициент корреляции Кендалла и соответствующего P-значения с
использованием функции kendalltau,
Тест хи-квадрат, U-тест Манна-Уитни.
